# 西安石油大学校园网认证

西安石油大学校园网认证脚本，比官方的更快更轻量，源码中 `Authentication.py` 文件可以直接嵌入软路由中。

## 使用方法

1. 运行 `GUI.py` 或发行版中的 `.exe`，填写用户名和密码后点击“保存数据”或“开始认证”。程序会在自身所在目录创建 `user_profile.json`。
2. 勾选“开机自启动（登录 Windows 后自动认证）”。下次登录 Windows 时，程序会正常显示界面，并使用已保存的信息自动开始认证。
3. 如果还没有 `user_profile.json`，或保存的账号信息不完整，开机启动时只会打开界面并提示，不会发起认证请求。

程序基于 Python 3。目前仅测试了西安石油大学的有线网络；其他学校理论上也可以使用，但可能需要在 `Authentication.py` 中调整 DNS 服务器和认证服务器等信息。

注意：使用过程中不要关闭窗口
